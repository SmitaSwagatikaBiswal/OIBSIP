# ***Basic Weather App***

A simple desktop weather application built with Python and Tkinter. It uses the OpenWeatherMap API to display current weather conditions and forecasts.

### Features
* Search weather by city
* Detect current location automatically
* Display temperature, humidity, wind speed, and condition
* Switch between Celsius and Fahrenheit
* Show weather icon
* 6-hour forecast
* 5-day forecast
* Handles API, network, and invalid-city errors
### Technologies Used
* Python
* Tkinter
* OpenWeatherMap API
* Requests
* Pillow
### Installation

1. Install the required libraries:\

pip install requests pillow

2. Add your OpenWeatherMap API key to the API_KEY variable in the Python file.

### Run\
python "Weather App.py"
### Project

This project was created to practice Python GUI development, API integration, and working with real-time weather data.
