# ***Random Password Generator***

A simple Python GUI application for generating secure random passwords with customizable options.

### Features
* Set password length from 8 to 64 characters
* Include uppercase and lowercase letters
* Include numbers and symbols
* Exclude ambiguous characters
* Password strength indicator
* Copy generated password to clipboard
* Stores the last 5 generated passwords
### Technologies Used
* Python
* Tkinter
* Secrets
* String
* Pyperclip
### How to Run
1.Install Python.\
2.Install the required library:\
pip install pyperclip\
### Run the program:
python "Random Password Generator.py"\
### Project

This project demonstrates Python GUI development, random password generation, clipboard functionality, and basic password strength evaluation.
